# 🌙 Sleep Tracker — Telegram-бот + Mini App для продажу курсу сну

Продукт складається з двох частин:

1. **Telegram-бот** (`bot.py`) — онбординг, трекер сну, ШІ-консультант, 7-денний платний інтенсив, приймання оплат через Monobank з підтвердженням адміном.
2. **Web Mini App** (`index.html`, `app.js`, `style.css`) — візуальний трекер сну, графіки, журнал і матеріали курсу.

Монетизація: **7-денний інтенсив сну за 99 грн** (одноразова оплата). Доступ (`is_premium`) видається **лише після підтвердження оплати адміністратором** — користувач не може активувати його самостійно.

---

## 🔐 Безпека (прочитайте перед запуском!)

- **Токен бота НЕ зберігається в коді.** Він читається зі змінної оточення `BOT_TOKEN`. Якщо змінна не задана — бот не запуститься.
- ⚠️ **Старий токен був у git-історії.** Обовʼязково **відкличте старий токен** через [@BotFather](https://t.me/BotFather) → `/revoke` і згенеруйте новий (`/token`). Використовуйте лише новий токен у `.env`.
- Файли `.env` та `sleep_ai_data.json` (база користувачів) виключені з git через `.gitignore`.

---

## ⚙️ Налаштування

1. Створіть бота у [@BotFather](https://t.me/BotFather), отримайте токен.
2. Дізнайтеся свій Telegram ID через [@userinfobot](https://t.me/userinfobot).
3. Скопіюйте приклад змінних оточення та заповніть його:

   ```bash
   cp .env.example .env
   ```

   Заповніть у `.env`:

   | Змінна | Опис | Обовʼязково |
   |---|---|---|
   | `BOT_TOKEN` | Токен бота від @BotFather | ✅ Так |
   | `ADMIN_IDS` | Telegram ID адмінів через кому (для підтвердження оплат) | ✅ Так |
   | `ADMIN_GROUP_ID` | ID групи для квитанцій про оплату (напр. `-1001234567890`) | Опційно |
   | `PORT` | Порт веб-сервера (Render задає сам) | Опційно |

## 🚀 Локальний запуск

```bash
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
python bot.py
```

Веб-додаток (Mini App) — статичні файли; локально можна відкрити так:

```bash
python3 -m http.server 8000
# далі відкрийте http://localhost:8000/index.html
```

## ☁️ Деплой на Render

1. Створіть новий **Web Service** і підключіть цей GitHub-репозиторій.
2. **Build Command:** `pip install -r requirements.txt`
3. **Start Command:** `python bot.py`
4. У розділі **Environment** додайте змінні: `BOT_TOKEN`, `ADMIN_IDS` (і за потреби `ADMIN_GROUP_ID`).
5. Render автоматично задає `PORT` — бот вже слухає його (health-check ендпоінт вбудований).

Mini App (папку зі статичними файлами) можна розмістити на будь-якому статичному хостингу (GitHub Pages, Netlify, Cloudflare Pages) і вказати URL у налаштуваннях бота через @BotFather → Menu Button / Web App.

## 💳 Як працює продаж курсу

1. Користувач у боті відкриває **«🎓 7-Денний Інтенсив сну»** → бачить пейвол (99 грн).
2. Натискає **«Придбати доступ»** → отримує посилання на банку Monobank.
3. Оплачує і надсилає боту квитанцію (скриншот).
4. Квитанція надходить адміну/в адмін-групу з кнопками **«✅ Прийняти»** / **«❌ Відхилити»**.
5. Після підтвердження — доступ до курсу відкривається автоматично (`is_premium = True`).

Адмін також може видати доступ вручну командою:

```
/grant TELEGRAM_USER_ID
```

Корисні адмін-команди: `/admin` (панель), `/buyers` (список покупців).
